# Odin Recipes

This project is part of the **Foundation Course** from [The Odin Proect](https://www.theodinproject.com)

## Description

The purpose of this project is to practice the basic concepts of HTML such as :

- HTML structure
- Headings and paragraphs
- List (ordered and unordered)
- Links
- Images

By completing this project, I will build a simple recipe website consisting of several pages that are connected using links.

## Skills Demonstrated

After finishing this project, I will have practiced:

- Writing basic HTML
- Structuring a simple webpage
- Creating links between pages
- Adding images to a webpage
